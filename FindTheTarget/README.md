# מציאת המטרה - FindTheTarget

משחק אנדרואיד פשוט שבו עליך ללחוץ על עיגול אדום שנע על המסך!

## תיאור המשחק

* לחץ על העיגול האדום כדי לצבור ניקוד
* יש לך 30 שניות לצבור כמה שיותר נקודות
* העיגול זז כל 1.5 שניות
* ככל שאתה מהיר יותר - כך תצבור יותר נקודות!

## התקנה

1. פתח את הפרויקט ב-Android Studio
2. לחץ על "Sync Project with Gradle Files"
3. הרץ את האפליקציה על אמולטור או מכשיר פיזי

## דרישות מערכת

* Android 5.0 (API 21) ומעלה
* Android Studio 2023.2.1 או גרסה חדשה יותר

## טכנולוגיות

* Kotlin
* Android SDK
* Material Design

## פיתוח

הפרויקט בנוי עם:
* Android Gradle Plugin 8.2.0
* Kotlin 1.9.10
* Target SDK 34
